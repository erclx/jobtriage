# Borrowed convention standards

## Porting from another repo

- When porting a convention from another repo built by the same maintainer on the same toolkit, replicate what it actually implements rather than the more automated version that seems like the natural next step.
- Check the source repo's own CI workflows and scripts before proposing new automation around a borrowed pattern.
