# Memory threshold standards

## Writing

- Save a feedback memory only when the same mistake happens twice in the session, or when the user explicitly corrects you.
- Keep a feedback memory to 3 lines: the rule, a one-line Why, and a one-line How to apply.
- Check for an existing memory file on the same topic before creating a new one. Update rather than duplicate.
